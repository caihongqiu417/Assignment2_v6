# Team01 · Hard_E3 安全反馈对照与下一轮建议

Hard_E3 是一次完成并通过核验的受控迭代。实验组 T 在这批固定模型评估中比同预算对照 C 少掉落、多获胜；按原定判据，跨评估组的改善方向仍有不一致。Team01 保留 T 作为后续研究起点，Hard_E2 为当前 Hard Final。本文前两节是已完成的训练与评估，后两节是利用既有轨迹形成的探索性诊断与待讨论提案。

## 1. 假设、训练和核验

观察到球在台边时，即使已经向内施力，已有的外向速度仍可能把它带出平台。本轮只测试一项训练差异：对离边距离短且外向速度高的状态，给策略小额安全反馈。固定风险定义为四边中最大的裁剪风险；外向速度为 `u`、离该边距离为 `d` 时，单边风险为 `clamp01(u²/14 − max(0, d − 0.25))`，其中 `u` 只取外向分量的非负部分。每次玩家动作按 `系数 × 风险 × 0.02 秒` 扣减。

两组从同一 `Team02_Medium_E1_seed1` 检查点初始化，均用训练 seed 1、PPO、Unity 2022.3.39f1 和 Hard 的 `OscillatingAxes` 对手。`Team02` 是同一团队旧记录的前缀。训练名义预算各 500,000 Hard 步，前 50,000 步包含在内，用于检查源加载、奖励和日志。两份训练配置除 run 身份外仅安全反馈系数不同。

## 3. T 的胜局与超时局：首撞推进和后续跟进

纳入全部 54 胜、22 超时；两类均发生过球间接触。以首次 `collision_enter` 为锚，将对手当时最近的台边固定为参考边。用锚点后第 10 个物理步的 `fixed_pre` 取样（约 0.20 模拟秒），计算沿该边法线的有符号净位移。下表的短窗在下一次新接触和终局前取样。首次玩家额外冲量分析只纳入实际记录到该事件的局，并在冲量时重新选择最近边。

| 观测 | 胜局 | 超时局 |
| --- | ---: | ---: |
| 每局接触次数中位数 | 1 | 4 |
| 首次接触时对手距最近边的中位数 | 1.794 | 1.873 |
| 首次接触后 0.20 秒向该边净位移中位数 | +0.779（54 局） | +0.118（22 局） |
| 上述净位移至少 0.5 的局数 | 32/54 | 5/22 |
| 有玩家额外冲量 | 53/54 | 14/22 |
| 首次玩家额外冲量朝最近边的分量 / 冲量模长，中位数 | 0.841 | 0.625 |
| 首次玩家额外冲量模长中位数 | 9.512 | 4.259 |
| 首次玩家额外冲量后 0.20 秒向该边净位移中位数 | +1.249（53 局） | +0.605（14 局） |
| 接触后对手球心曾到距任意边 0.5 以内 | 54/54 | 9/22 |

更普遍的瓶颈是第一次接触的有效推进不足。超时局里的 14 次首次玩家额外冲量都至少有一部分朝当时的最近边，方向偏离和冲量较小同时存在，无法将差异只归给其中一项。净位移也受撞击前对手速度、普通物理解算和对手动作影响。

跟进是另一个可见分支。超时局中 9 局曾到近边区，其中 8 局首次到近边后退回该边内侧至少 1 单位，期间 0 局发生新的球间接触，且进入近边区时均未处于记录的持续接触中。对手退回耗时 0.50–1.78 秒，8 局中有 7 局在退回时双方距离比进入近边区时更大。另 1 局在距超时约 0.36 秒时才达到诊断线。可用 `02_T_seed2026110301` 第 5 局复核：对手约在 4.76 秒进入近边区，0.50 秒后退回；本局五次接触仍超时。这里的近边线和回退线是探索性读数，缺少新接触只能描述轨迹，无法证明贸然追击必然能取胜。

## 4. 下一轮提案：从 T 检查点测试一项有效推进反馈

建议优先奖励接触后的净推进。先测试如下候选：新球间接触时选定对手最近的边；0.20 秒后，沿同一边的法线计算对手净推进。起算点取撞击时位置与本局同侧已得分位置的较外者。推进至多 0.25 单位时得 0；0.25 到 1.0 单位之间线性增加，每个窗口最多 +0.01，每局最多 +0.03。一次只开一个窗口，结算步不重开；若不足 0.20 秒已结束，按原终局奖惩结算。这样给持续向外的实质推进加分，同时减少同一位置反复撞击的收益。候选为经验性塑形项，需要用原规则下的胜平负验证其效果。[Ng、Harada 与 Russell 的奖励塑形研究](https://people.eecs.berkeley.edu/~russell/papers/icml99-shaping.pdf)

用原有 T 100 局作离线重算，赢／超时／输三类的平均假想加分分别为 **0.00914 / 0.00505 / 0.00294**，有加分的局数分别是 **48/54、17/22、15/24**；观察到的最高单局约 0.02059。该结果用来检查量级及重叠，训练中的实际行为和胜率需要另行评估。

原版 T 是起点成绩参考，同预算的 T-Continue 用来控制多训练一段本身的影响。现阶段的步数、系数和门槛均是下一轮建议，尚无新训练或评估结果。E3 两臂共用约 102 分钟取得相对 C 的 10 个百分点增益，而对当前 Final 的胜率差仅 4 个百分点且受单组影响。缩小下一轮预算并预先指定过程目标，可以先判断这一项改变值不值得继续投入。
